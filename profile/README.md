### 👋 About ML204

**ML204** is an open-source initiative dedicated to making Machine Learning and Artificial Intelligence intuitive, visual, and hands-on. Instead of treating AI as a black box of dense equations, we build interactive learning experiences where anyone can experiment with algorithms, explore mathematical foundations visually, and build real intuition from the ground up.

### ✨ What We Focus On

- **📖 Interactive Learning:** Concept-driven chapters blending clear explanations with live, manipulable visualizations.
- **🔬 Visual Experimentation:** Hands-on simulations that let learners tweak parameters and observe model behavior in real time.
- **📱 Accessible Anywhere:** Built for seamless reading across web and offline-capable mobile experiences, complete with eye-care reading modes.
- **🌍 Open-Source Community:** Built in the open—welcoming learners, educators, researchers, and developers to learn and contribute together.

### 🗂️ Flagship Project

- **[ML204](https://github.com/ML204/ML204)** — Our core interactive Machine Learning book and cross-platform learning application built with TypeScript, Next.js, MDX, and Capacitor.
